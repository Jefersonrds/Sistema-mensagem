# Sistema de Mensagens - Projeto de Estudos em POO

## 📚 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de aprofundar os conhecimentos em Programação Orientada a Objetos (POO) utilizando a linguagem Java. Trata-se de um sistema de mensagens que simula o envio e recebimento de mensagens entre usuários, aplicando conceitos fundamentais da POO como encapsulamento, herança e polimorfismo.

## 🎯 Objetivos

- Praticar os pilares da POO em um cenário prático.
- Implementar classes e métodos que representem um sistema de mensagens.
- Simular interações entre usuários, como envio e recebimento de mensagens.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java
- **Paradigma:** Programação Orientada a Objetos (POO)

## 🚀 Como Executar o Projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Jefersonrds/Sistema-mensagem.git

2. **Navegue até o diretório do projeto:**
  ```bash
  cd Sistema-mensagem
```
3. **Compile o projeto:**
```bash
  javac Main.java
```
4. **Execute o projeto:**
```bash
  java Main
```
